# Smart Personal Finance & Expense Tracking App

## Overview
This project is a UI/UX case study for a FinTech mobile application focused on personal finance and expense tracking.

## Features
- Expense Tracking
- Budget Analytics
- Dashboard UI
- Profile Management
- Clean Mobile Interface

## Screens Included
1. Splash Screen
2. Login Screen
3. Home Dashboard
4. Expense Tracking
5. Budget Analytics
6. Profile Screen

## Tools Used
- Figma
- Google Fonts
- Material Icons

## Objective
To create a user-friendly and modern finance management mobile application.

## Conclusion
This project demonstrates a complete mobile UI/UX workflow including user flow, interface design, and financial analytics dashboard.
